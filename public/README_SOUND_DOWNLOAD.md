# Achievement Sound Download Instructions

To add the Minecraft achievement sound:

1. Visit: https://www.myinstants.com/en/instant/minecraft-advancement-challenge-complete-21471/
2. Click the download button on the page
3. Save the file as `achievement-sound.mp3` in this `public` folder

Alternatively, you can download from:
- https://soundxpro.com/sounds/minecraft-advancement-challenge-complete

The sound file should be named exactly: `achievement-sound.mp3`

Once the file is in place, the achievement notification will automatically play this sound when achievements are unlocked.
